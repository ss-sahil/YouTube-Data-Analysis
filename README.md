# YouTube-Data-Analysis
A YouTube data analysis and visualization case study using Python, NumPy, Pandas, Matplotlib and Seaborn.
# YouTube Data Analysis

## About the Project

This project is a case study based on YouTube video data. 
The project analyzes views, likes, comments and video categories.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed

- Mean
- Median
- Standard Deviation
- Grouping and Aggregation
- Sorting and Filtering
- Correlation

## Data Visualization

### Matplotlib
- Line Chart
- Bar Chart
- Histogram
- Pie Chart
- Scatter Plot

### Seaborn
- Box Plot
- Violin Plot
- Heatmap
- Count Plot
- Pair Plot

## Conclusion

The analysis shows that Tech videos have the highest average views 
in the given dataset. Views, likes and comments also show a 
positive relationship.
